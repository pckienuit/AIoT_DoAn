\section{Kiến trúc hệ thống}

\subsection{Tổng quan}
Hệ thống được chia thành ba khối chính:

\begin{itemize}
  \item \textbf{Web Client}: phục vụ đặt vé, chọn ghế, thanh toán mô phỏng, đăng ký khuôn mặt và tra cứu vé.
  \item \textbf{Server}: cung cấp REST API, quản lý dữ liệu nghiệp vụ, lưu vector khuôn mặt và điều phối đồng bộ.
  \item \textbf{MaixCAM Edge}: nhận ảnh camera, trích xuất embedding, đối sánh cache cục bộ và hiển thị kết quả.
\end{itemize}

\subsection{Luồng đăng ký khuôn mặt}
\begin{enumerate}
  \item Người dùng đặt vé và chọn đăng ký khuôn mặt.
  \item Web client thu thập ảnh hoặc video, kiểm tra chất lượng và tạo embedding.
  \item Vector được gửi tới API \texttt{/api/face/register}.
  \item Server gắn vector với booking và lưu vào Qdrant.
\end{enumerate}

\subsection{Luồng nhận diện tại MaixCAM}
\begin{enumerate}
  \item MaixCAM gọi \texttt{/api/sync/\{flight\_id\}} để tải cache hành khách của chuyến bay.
  \item Server mã hóa vector trước khi trả về thiết bị.
  \item Thiết bị lưu cache mã hóa và chỉ giải mã vào RAM khi đối sánh.
  \item Khi có khuôn mặt trước camera, MaixCAM trích xuất embedding và tính khoảng cách cosine với cache.
  \item Nếu match, thiết bị hiển thị thông tin vé; nếu không match, có thể gọi API fallback.
\end{enumerate}
